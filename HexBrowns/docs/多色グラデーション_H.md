# 多色グラデーション_H

オブジェクトに最大 5 色のグラデーションを重ねるアニメーション効果です。
azurite氏の `グラデーション+` をもとに、色を 2 色から 5 色まで増やし、中間色の位置を動かせるようにしました。
色の混ぜ方は、sRGBのほかOklab / Oklchなどの色空間から選べます。

## インストール

1. `Script\多色グラデーション_H.anm2` を置く。
2. AviUtl2を起動する。
3. フィルタ効果の追加から **HexScript → 多色グラデーション_H** を選ぶ。

元の `グラデーション+` とは名称が違うため競合の心配は不要です。

## 使い方

1. テキストや図形に多色グラデーション_Hを追加する。
2. **色数** を選び、**開始色**・**中間色 1〜3**・**終了色** を決める。
   色は 開始色 → 中間色1 → 中間色2 → 中間色3 → 終了色 の順に並ぶ。
3. **形状** と **角度**・**幅** で、色の並ぶ向きと長さを決める。
4. 中間色の位置を自分で決めたいときは **位置を等間隔にする** を外し、**中間色n位置** を動かす。

## パラメータ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 強さ | 0 ~ 100 | 100 | グラデーションを重ねる強さ |
| 中心X / 中心Y | -5000 ~ 5000 px | 0 | グラデーションの中心 |
| 角度 | -3600 ~ 3600 | 0 | 色の並ぶ向き |
| 幅 | 0 ~ 2000 px | 100 | 開始色から終了色までの長さ。幅の基準が ピクセル のとき効く |
| 合成モード | 通常 / 加算 / 減算 / 乗算 / スクリーン ほか | 通常 | 元の色への重ね方 |
| 形状 | 線形 / 円形 / 矩形 / 凸形 / 角丸矩形 と各ループ | 線形 | 色の広がる形 |
| 色空間 | sRGB / Linear sRGB / HSV / HSL / L\*a\*b / LCh / Oklab / Oklch | Linear sRGB | 色を混ぜる空間 |
| 補間経路 | 短経路 / 長経路 | 短経路 | 色相を回る向き。HSV・HSL・LCh・Oklchのとき効く |
| 開始色 / 終了色 | 色 | 白 / 黒 | 両端の色 |
| 開始色透明度 / 終了色透明度 | 0 ~ 100 | 0 | 両端の色の透明度 |
| 色数 | 2色 ~ 5色 | 2色 | 使う色の数。使わない中間色の欄は隠れる |
| 位置を等間隔にする | オン / オフ | オン | オンなら中間色を等間隔に並べる |
| 中間色1〜3 | 色 | 赤 / 緑 / 青 | 中間の色 |
| 中間色1〜3透明度 | 0 ~ 100 | 0 | 中間の色の透明度 |
| 中間色1〜3位置 | 0 ~ 100 % | 25 / 50 / 75 | 中間の色の位置。等間隔を外したとき効く。前の色より手前にすると前の色の位置に揃う |
| 幅の基準 | ピクセル / 画像サイズ | ピクセル | 画像サイズ なら、幅(%) の 100% でオブジェクトの端から端まで届く |
| 幅(%) | 0 ~ 1000 % | 100 | 幅の基準が 画像サイズ のときの幅 |

## 注意事項

- 2 色のときは、不透明な部分は元の `グラデーション+` と同じ絵になります。半透明の縁は、元のスクリプトより素材の透明度をそのまま保ちます
- `.aup2` の `effect.name=グラデーション+` を `effect.name=多色グラデーション_H` に書き換えると、元の設定値がそのまま読めます。色数は 2色 になります
- 設定項目の名称は保存データのキーなので、今後も変えません

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| テキストを並べたグループ制御に掛けて描き直したとき、まれにグラデーションが崩れ、ログに `invalid buffer type. name=cache:multigradient_h/orig_…` が出る | 古い版の症状。最新バージョンに更新する |
| 中間色が出ない | 色数を 3色 以上にする |
| 中間色の位置が動かない | 位置を等間隔にする を外す |
